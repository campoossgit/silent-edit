# Silent Edit

Este repositório foi preparado para funcionar como uma landing page simples do plugin Silent Edit para Valanced.

## Estrutura

- `index.html` - página inicial com os botões "Copy" e "Source"
- `script.js` - lógica do botão "Copy", que copia a URL atual da página

## Como usar

1. Hospede a página em qualquer hosting estático.
2. O botão "Copy" vai copiar a URL atual da página.
3. O botão "Source" leva para o repositório do projeto.
